# data/synthetic

Generated by `make data` (i.e. `python -m apps.producer.main generate --out data/synthetic`).

Contents (all gitignored except this file):

- `nominal.parquet` — 8 links x 4 h @ 1 Hz, no impairment.
- `soft_fail.parquet` — 4 links x 2 h for each of `edfa_aging`, `fiber_pinch`,
  `dirty_connector`, `laser_drift`; onset at 30 min, hard failure 12-25 min after onset.
- `los.parquet` — 2 links with a sudden step LOS at 60 min (negative control).
- `reroutes.jsonl` — appended by `path_manager` for every accepted reroute.

If `pyarrow` is unavailable the generator falls back to `.csv` with the same names.
